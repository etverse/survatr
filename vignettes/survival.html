Causal survival analysis: NHEFS Ch. 17 walkthrough

  • Show All Code
  • Hide All Code
  • View Source

This vignette walks through the Chapter 17 analysis of Hernán and Robins (2025) using survatr’s two-step API. The analysis estimates the effect of smoking cessation (qsmk) on 10-year all-cause mortality in the NHEFS cohort.

Reference target (Hernán and Robins 2025, Program 17.2): 120-month standardised survival ≈ 80.7% under cessation, ≈ 80.5% under no cessation; risk difference ≈ 0.2% (95% CI −4.1% to 3.7% — essentially null).

Data

The nhefs_surv dataset ships with survatr. It was assembled from causaldata::nhefs (Huntington-Klein 2021) by expanding each of the 1629 participants to a rectangular person-period grid of 120 monthly rows.

Each row is one person-period: one individual in one calendar month. The event column is 1 only in the month of death for the 318 participants who died before December 1992; it is 0 in all other rows. The nine confounders from Table 17.1 are carried as baseline values across all rows for each participant.

Step 1 — Fit the hazard model

The discrete-time hazard model follows Program 17.2: a pooled logistic regression (D’Agostino et al. 1990) of event on qsmk, the nine confounders, a quadratic time baseline, and treatment-by-time interactions.

Code 
fit <- surv_fit(
  nhefs_surv,
  outcome      = "event",
  treatment    = "qsmk",
  confounders  = ~ sex + race + age + I(age^2) +
    education +
    smokeintensity + I(smokeintensity^2) +
    smokeyrs + I(smokeyrs^2) +
    exercise + active + wt71 + I(wt71^2),
  id           = "seqn",
  time         = "time",
  ## Quadratic time baseline + treatment-by-time interactions (H&R Ch. 17).
  time_formula = ~ time + I(time^2) + qsmk:time + qsmk:I(time^2),
  estimator    = "gcomp"
)

Step 2 — Survival curves and risk difference

contrast() takes the fitted model and returns time-indexed estimates and contrasts under each intervention.

Code 
times <- seq(12L, 120L, by = 12L)

res <- contrast(
  fit,
  interventions = list(
    cessation    = static(1),
    no_cessation = static(0)
  ),
  times     = times,
  type      = "survival",
  ci_method = "sandwich"
)

## Standardised survival curves at each annual checkpoint.
res$estimates

The risk difference under cessation vs. no cessation at 120 months:

Code 
rd <- contrast(
  fit,
  interventions = list(
    cessation    = static(1),
    no_cessation = static(0)
  ),
  times     = 120L,
  type      = "risk_difference",
  ci_method = "sandwich"
)
rd$contrasts

The point estimate (≈ 0.2 pp) and the sandwich 95% CI both agree with the published analysis: smoking cessation has essentially no detectable effect on 10-year mortality in this observational cohort after confounder adjustment.

RMST

The restricted mean survival time (RMST) up to 120 months summarises the survival curve as a single number: the area under \(\hat{S}^a(t)\) from 0 to \(t^* = 120\).

Code 
rmst <- contrast(
  fit,
  interventions = list(
    cessation    = static(1),
    no_cessation = static(0)
  ),
  times     = times,
  type      = "rmst_difference",
  ci_method = "sandwich"
)
rmst$contrasts

RMTL (restricted mean time lost)

Restricted mean time lost is the complement of RMST within the same window, \(\mathrm{RMTL}^a(t^*) = t^* - \mathrm{RMST}^a(t^*) = \int_0^{t^*} (1 - \hat{S}^a(u))\,du\). It is the same curve viewed from the other side, so the standard error is identical to RMST’s (the constant \(t^*\) drops out of the gradient).

Code 
rmtl <- contrast(
  fit,
  interventions = list(
    cessation    = static(1),
    no_cessation = static(0)
  ),
  times     = times,
  type      = "rmtl_difference",
  ci_method = "sandwich"
)
rmtl$contrasts

Survival quantiles

The \(q\)-quantile of survival time is the first \(t\) at which \(\hat{S}^a(t)\) drops to \(1 - q\) (the median is \(q = 0.5\)). On this NHEFS cohort survival stays above \(\approx 0.8\) through 120 months, so the median is beyond the follow-up window and q = 0.5 would abort with survatr_quantile_unreached — a long survival horizon is exactly when you report a low quantile (or RMST) instead. Here we report the 10th and 15th percentiles of survival time; pass a vector of q to get several at once. The result is indexed by q, and a difference in quantile survival time is reported when there are two interventions.

Code 
quant <- contrast(
  fit,
  interventions = list(
    cessation    = static(1),
    no_cessation = static(0)
  ),
  times     = times,
  type      = "quantile",
  q         = c(0.10, 0.15),
  ci_method = "sandwich"
)
quant$estimates

Cluster-robust standard errors

When individuals are nested in clusters that share unobserved drivers of the outcome — multi-site studies, households, providers, repeated enrolment — the observations are no longer independent and the per-individual sandwich understates the variance. Pass cluster = "<column>" (a person-period column that is constant within id) and the sandwich becomes cluster-robust: the per-individual influence functions are summed within cluster before the cross-product, so the independent unit becomes the cluster. The point estimate is unchanged, and cluster = "<id-column>" reproduces the per-individual sandwich exactly (every cluster is a singleton).

The illustration below simulates 40 sites with a shared site-level frailty on the hazard, so individuals within a site are positively correlated. The cluster-robust risk-difference CI is appropriately wider than the naive one.

Code 
set.seed(11)
n_per <- 25L
n_site <- 40L
K <- 8L
u <- rnorm(n_site, sd = 1.4) # site-level frailty
rows <- list()
idx <- 0L
for (g in seq_len(n_site)) {
  for (j in seq_len(n_per)) {
    idx <- idx + 1L
    A <- rbinom(1L, 1L, 0.5)
    h <- plogis(-2 + seq(0, 0.3, length.out = K) - 0.5 * A + u[g])
    Y <- rbinom(K, 1L, h)
    first <- which(Y == 1L)[1L]
    if (!is.na(first) && first < K) Y[(first + 1L):K] <- 0L
    rows[[idx]] <- data.frame(id = idx, site = g, t = seq_len(K), A = A, Y = Y)
  }
}
multisite <- do.call(rbind, rows)

fit_ms <- surv_fit(
  multisite, "Y", "A", ~1, "id", "t",
  time_formula = ~ factor(t)
)
ivs <- list(treated = static(1), control = static(0))

naive <- contrast(
  fit_ms, ivs,
  times = c(4, 8), type = "risk_difference", ci_method = "sandwich"
)
clustered <- contrast(
  fit_ms, ivs,
  times = c(4, 8), type = "risk_difference", ci_method = "sandwich",
  cluster = "site"
)

## Same point estimate; the clustered SE / CI is wider.
data.frame(
  time          = naive$contrasts$time,
  rd            = round(naive$contrasts$estimate, 4),
  se_naive      = round(naive$contrasts$se, 4),
  se_clustered  = round(clustered$contrasts$se, 4)
)
#>   time     rd se_naive se_clustered
#> 1    4 0.0535    0.022       0.0215
#> 2    8 0.0754    0.031       0.0309

The bootstrap honours the same unit of independence — ci_method = "bootstrap" with cluster = "site" resamples whole sites rather than individuals. Cluster-robust SEs are available for the gcomp, IPW, IPCW, and competing-risks paths; longitudinal ICE-hazard fits are not yet supported.

outcome — multi-site studies, households, providers, repeated enrolment — the
observations are no longer independent and the per-individual sandwich
*understates* the variance. Pass `cluster = "<column>"` (a person-period column
that is constant within `id`) and the sandwich becomes cluster-robust: the
per-individual influence functions are summed within cluster before the
cross-product, so the independent unit becomes the cluster. The point estimate
is unchanged, and `cluster = "<id-column>"` reproduces the per-individual
sandwich exactly (every cluster is a singleton).
